# Ollama Cloud Setup

## Topic
How to run any model on the cloud using Ollama.

## Structure
- Setup (Ollama install, env)
- Model pull (e.g., llama3.2:3b)
- Cloud exposure (Cloudflare tunnel / public URL)
- Security (env vars for secrets, no hardcoding)
- Usage (curl / API)

## Details
- Platform: Ubuntu 24.04 / Google Cloud Shell
- Protocol: SSH (gh auth)
- Languages: English + Bengali
